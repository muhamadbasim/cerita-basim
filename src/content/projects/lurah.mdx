## Masalah

Mengelola konfigurasi Cloudflare lewat dashboard itu lambat dan error-prone. Saya butuh cara cepat untuk audit semua zone, DNS records, page rules, dan WAF settings dari terminal.

## Solusi

Lurah adalah CLI tool yang membaca konfigurasi Cloudflare via API dan menghasilkan laporan audit — mana yang best practice, mana yang perlu diperbaiki.
