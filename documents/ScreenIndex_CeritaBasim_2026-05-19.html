Catatan prototype

  • Semua screen link ke cerita-basim.css (shared stylesheet, .css extension).
  • Dark mode toggle berfungsi di semua screen (localStorage persisted).
  • Komentar form: Turnstile mock, submit simulasi, pending toast.
  • Reaksi: toggle, counter update, bounce animation.
  • Filter (Karya + Cerita): client-side, instant, empty state.
  • Subscribe: double opt-in flow (form → thanks page).
  • Admin Dispatch: real-time progress bar simulasi dengan log.
  • Modal (Subscribers): open/close via X, backdrop, Escape key.
  • Responsive: desktop, tablet, mobile breakpoints.
  • Accessibility: skip-to-main, focus-visible, ARIA labels, min 44px touch targets.
